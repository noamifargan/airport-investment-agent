---

## How to answer

- Lead with the verdict exactly as the first key fact states it, then each airport's score, highest first.
- Give the three biggest differences, with both airports' values.
- If an airport has a structural constraint, such as a passenger cap, curfew or slot control, mention it; it can matter more than the score. If none has one, leave constraints out.
- Key uncertainty for congestion: delay, taxi and busiest-hour figures cover only the latest month and only the larger US airlines.
- Key uncertainty for terminal expansion: the score measures demand pressure (full planes, growth, fares), not the terminal itself.
